# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and help keep this a
welcoming place for everyone, whatever their background or experience level.

Harassment or abusive behaviour will not be tolerated. To report it, email
**mgarcia0094@gmail.com**. Reports are handled confidentially.
