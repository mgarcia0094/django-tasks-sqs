# Security Policy

## Supported versions

Security fixes go into the latest released version.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately
through [GitHub's security advisories](https://github.com/mgarcia0094/django-tasks-sqs/security/advisories/new).

Include what you found, how to reproduce it and its impact. You'll get an answer within
a week, and credit in the release notes if you'd like.
